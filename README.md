# The Build Loop — Claude Skill

A [Claude Skill](https://www.anthropic.com/news/skills) that runs the Build Loop operating model inside Claude.

> Frame the problem. Build something testable. Validate with real people. Decide.

Learn more at [thebuildloop.com](https://thebuildloop.com).

## Install

Download the latest `build-loop.skill` bundle from [Releases](https://github.com/rosspchapman/build-loop-skill/releases/latest) and add it to Claude.

## Releases

This repo exists to version and distribute the skill bundle. Each release attaches `build-loop.skill` as an asset. The "always latest" download URL is:

```
https://github.com/rosspchapman/build-loop-skill/releases/latest/download/build-loop.skill
```
